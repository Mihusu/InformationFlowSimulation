approach, this in turn requires a definition of the actors/roles in the program.

  * Answer: A definition of a lattice of security labels can be seen in the report
  

* The labeling of all inputs, outputs, and variables of the program with such labels
  * Can be seen in the report with relevant and used variables that are going 
    back and forth between backend and the database


* An information flow analysis of the program, i.e., that there are no information
flows that the security policy forbids.
  * Answer: Can be seen in the report
